# Brand assets

Source files for the KindredTrips brand. Not served by the live site — these are reference/archive files.

## Files

- **`brand-guidelines.png`** (1448×1086) — full style sheet: primary + secondary logo, color palette, typography (Playfair Display / DM Sans / Caveat), brand keywords, button/card/header treatments. Use when redesigning anything.
- **`logo-cream-bg.png`** (1672×941) — logo composited on the brand cream background. Use when you need a non-transparent version (e.g. social posts, decks).

The transparent canonical logo lives at the repo root as `/logo.png` and is what every page renders.
